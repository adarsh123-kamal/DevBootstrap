# payment-service

A FastAPI backend service generated by DevBootstrap.

## Requirements

- Python 3.12 or newer

## Setup and run

```bash
python -m venv .venv
# Activate .venv for your operating system, then:
python -m pip install -r requirements.txt
python -m app.main
```

The configured `PORT` is used when running the module. For auto-reload during development, use `uvicorn app.main:app --reload` instead. Open `http://127.0.0.1:8000/` for service information, `/health` for a health check, or `/docs` for interactive API documentation.

## Configuration

Copy `.env.example` to `.env` as a reference, then set `APP_NAME`, `ENVIRONMENT`, `PORT`, and `DEBUG` in your process environment. The app uses safe defaults and does not load `.env` files automatically.

## Tests

```bash
python -m pytest
```

## Project layout

- `app/main.py` creates the FastAPI application.
- `app/routes/health.py` contains the health endpoint.
- `app/core/config.py` loads environment-backed settings.
- `app/core/logging_config.py` configures JSON logs.
- `tests/` contains endpoint and configuration tests.
