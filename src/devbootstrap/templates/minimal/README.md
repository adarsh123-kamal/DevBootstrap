# __SERVICE_NAME__

A dependency-free Python service starter generated by DevBootstrap.

## Requirements

- Python 3.12 or newer

## Setup and run

```bash
python -m venv .venv
# Activate .venv for your operating system, then:
python -m app.main
```

The health check is available as `app.main.health_check()` for use by a host or future adapter.

## Configuration and logging

The service reads `APP_NAME`, `ENVIRONMENT`, `PORT`, and `DEBUG` from the process environment. `.env.example` documents the variables; `.env` files are not loaded automatically. JSON logging is configured by `app.core.logging_config`.

## Tests

Install pytest in your environment and run:

```bash
python -m pytest
```

## Project layout

- `app/main.py` contains the service entry point and health check.
- `app/core/config.py` loads environment-backed settings.
- `app/core/logging_config.py` configures JSON logs.
- `tests/` contains service tests.
